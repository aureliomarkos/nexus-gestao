Objetivo: Gerar um Dashboard Administrativo completo, moderno e responsivo para o aplicativo Nexus - Gestão Centralizada de Infraestrutura.

Formato: O resultado deve ser um ÚNICO ARQUIVO HTML que inclua:

O HTML completo.

Tailwind CSS (via CDN).

Todo o JavaScript necessário para a interatividade e consumo de API (CRUD).

Estética e Design:

Tema: Profissional, limpo, moderno.

Cores: Usar a cor Laranja (orange-600/700) como cor primária para botões, badges, tags e elementos de destaque, conforme solicitado. Usar cinza/neutro (gray) para fundo e texto.

Layout: Sidebar fixa na esquerda para navegação principal. O layout deve ser 100% responsivo (otimizado para Mobile e Desktop).

Integração com API (CRUD Completo):

A URL base da API deve ser definida: const API_BASE_URL = "http://127.0.0.1:8000";.

O JavaScript deve implementar as operações CRUD (GET, POST, DELETE) para o módulo Desenvolvedores e garantir a exibição do ID em cada registro para permitir as ações de Editar e Excluir.

Deve haver uma função genérica de fetchData que lida com erros de rede/HTTP e exibe mensagens de alerta (utilizar modal customizado, NUNCA alert()).

Estrutura de Navegação (Módulos Principais e Endpoints):
O dashboard deve ter quatro abas principais, cada uma com seu endpoint de listagem correspondente:

Desenvolvedores (GET /desenvolvedores)

Clientes (GET /clientes)

Projetos (GET /projetos)

Infraestrutura (GET /infra)

Módulo 1: Desenvolvedores (CRUD Detalhado)

Visualização: Exibir os dados em um GRID responsivo de cartões e também em uma Tabela (deve haver um toggle entre Grid e Tabela).

Cartões/Tabelas: DEVE conter botões de "Editar" e "Apagar" que ativem as funções POST e DELETE, respectivamente, usando a primary key do registro.

Dados Exibidos (Cartão/Tabela): Nome, Email, Tipo de Contrato (com badge laranja), Taxa Horária e Endereço (Cidade/Estado).
